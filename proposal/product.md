# 產品定義：狼人殺第一天法官

## 產品定位

這是一個**面對面狼人殺的自動化法官工具**，以純前端 Web App 形式運行。遊戲時將手機或平板放置桌面中央，由玩家自行操作夜間行動，程式負責所有流程控制、時間調度與結算邏輯，完全不需要真人法官。

## 目標用戶

- 面對面狼人殺玩家群組（朋友聚會、桌遊團等）
- 希望省去法官角色，讓所有人都能參與遊戲的群體
- 熟悉各種狼人殺板子與規則，並追求高效無失誤結算的玩家

## 核心功能

### 遊戲設定與靈活配置
- 支援 6～16 人局（含娛樂局如獵殺潛狼、連連看）
- 內建數十種預設板子配置（經典、夢魘攝夢、狼美人、覺醒系列、第三方陣營板等）
- 三大陣營體系：狼人陣營、好人陣營、第三方陣營（咒狐、混血兒、邱比特、殭屍、潘朵拉、覺醒孤獨少女等）
- 支援全資料驅動 (Data-Driven) 配置：角色的查驗結果、技能目標數、自我選擇限制、免疫規則等皆由底層資料定義，確保擴充與自訂的高彈性。
- 可選規則：女巫首夜自救、上警環節開關、系統隨機發牌、閉眼到睜眼的間隔秒數
- 支援板子的特殊性別與條件配置（如開膛手傑克性別、睡美人抽選）
- 若兩角色不在同一板子，無需考慮兩者的交互關係

### 非同步夜晚流程
- 自動依照 `wake_queue` 建立夜晚行動佇列
- 採用精準的非同步語音播報（Web Speech API + Promise）提示睜眼/閉眼，確保流程不卡頓
- 各角色技能選擇介面自動依據 `ui_type` 渲染（純確認、單選、多選、特殊面板）
- 處理偽裝睜眼（棄牌角色）、恐懼（夢魘）、冰凍（企鵝）、技能被偷（灰太狼）等特殊異常狀態

### 行動隊列與精準結算
- 將夜晚的所有操作收斂為標準的「行動隊列 (Action Queue)」與「狀態流 (Status Flow)」
- 自動計算狼刀、毒殺、反傷、護盾、攝夢等複雜交互
- 連帶死亡鏈遞迴處理（殉情、攝夢連線、尋香綁定、鬼魅新娘）
- 特殊免死與屬性判定（白貓翻牌、惡靈騎士反傷、覺醒白痴保護、鏽劍感染）

### 白天階段與法官面板
- 顯示死亡名單與熊咆哮結果
- 開槍/技能發動佇列（獵人、狼王、覺醒狼王、黑市武器等）
- 詭術師/魔術師換票結算
- 隨機發言順序生成
- 煉金魔女法老之蛇（白天發言後決策）
- 提供「法官紀錄面板」，可一鍵查看所有玩家當前身上的標記（被恐懼、被魅惑、中度、護盾等）及昨晚詳細行動日誌。

### 警長競選
- 上警名單選擇
- 隨機決定發言起點與方向
- 狼人自爆跳過機制
